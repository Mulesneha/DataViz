📊DataViz: Data Visualization Dashboard📊

📌 Project Overview
This is a **Flask-based Data Visualization web application** that allows users to upload and analyze CSV data and visualize it using interactive charts.
A Data Visualization Dashboard is an interactive system used to represent data in the form of charts, graphs, tables, and visual reports. It helps users analyze large amounts of information quickly and make better decisions by presenting complex data in a simple and understandable format. The dashboard collects data from different sources, processes it, and displays meaningful insights using visual components such as bar charts, pie charts, line graphs, and heat maps.
